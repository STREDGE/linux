# ТЗ: SA Living 0.2.0 — «мозг» целиком для игры в одиночку (с голосом)

Согласовано с игроком 2026-11-26. **Пока не начинать** — игрок скажет «начинаем».

Цель игрока: **протестировать мозг ИИ в одиночку, с голосом и всем остальным — не сырую версию, а сразу всё
за один заход.** Значит, выпуск 0.2.0 должен работать целиком от первого запуска до долгой игры, а всё, что можно
проверить без телефона, — проверено на компьютере до отправки.

Основа: всё из 0.1.0 (`README.md`, `DESIGN.md`, `docs/01…06`) + незаконченное из `STATUS.md` §5.
Кооп-часть (`docs/TZ-1.1.md` §7а в корне) — **не в этом выпуске**, только не ломать её заготовки.

## 1. Что входит (всё сразу)

### 1.1 Речь без Google
* **Распознавание** твоей речи — GigaAM v3 (sherpa-onnx), на телефоне, без интернета.
* **Голоса педов** — свой движок xVibe; у каждого персонажа свой постоянный голос (по полу, возрасту, роли:
  коп, бандит, прохожий), разнообразие — высота и скорость. В наборе: 3 голоса, которые игрок одобрил
  (`docs/samples/xvibe_ru_10_voices_v2.wav`, 0:23 / 0:27 / 0:33: Vosk M01 ×1.1, M02, F01 ×0.88),
  эталон автора, + **свои голоса**: игрок добавляет образец 15–20 с (свой, друга) — «Добавить голос»
  (образцы игрока в репозиторий не кладутся).
* **Склейка** (`src/speech/speech.cpp`, обновить `speech.h`): загрузка движков, свой поток для голоса
  (без просадок FPS), очередь фраз, «перебить» (пед замолкает, если ты заговорил), микрофон 16 кГц.
* **Быстрый ответ**: ИИ пишет ответ потоком → первая фраза озвучивается, пока пишется вторая. Цель —
  пед начинает говорить через **≤ 2–3 с** после конца твоей фразы.
* **Выбор движка** в «AI»: «Свой голос (без Google)» по умолчанию / «Google» (запасной).

### 1.2 Меню «AI» — первый запуск без возни
* Мастер первого запуска: 1) ключ («Вставить из буфера» → «Проверить»), 2) «Скачать распознавание» (мод качает
  сам, с процентами), 3) «Импорт голосового пакета» (из `Download`, файл придёт в чат), 4) «Проверить микрофон»
  (скажи фразу — покажет текст), 5) «Проверить голос» (послушать голоса).
* **Экран «Состояние»**: ключ, интернет, распознавание, голоса, микрофон, расход — каждый пункт «работает / нет и
  что нажать». Плюс надписи о ключе из ТЗ 1.1 §7а (в одиночке — «Используется твой ключ» / «Вставьте ключ»).
* **Расход**: сколько потрачено сегодня/всего, **лимит в день** (по умолчанию разумный, можно менять),
  при лимите — «мозг реализма» и сообщение.

### 1.3 Подсказка для ИИ (чтобы голос звучал правильно)
Ударения `+гласная`, числа и сокращения словами, короткие живые реплики, без смайлов и непроизносимого.

### 1.4 Поведение (доделать)
* **Групповой разговор** с бандой/компанией: сцена на нескольких педов, у каждого свой голос, свои реплики и
  действия, говорят по очереди, перебивают друг друга как люди.
* **Забывание неважных персонажей**: кто не связан с делом, бандой, номером телефона — забывается через N игровых
  дней (память не растёт бесконечно).
* **Без ключа / без интернета** — «мозг реализма» (копы, банды, прохожие умнее) работает всегда; разговор —
  короткие реплики из набора без ИИ, понятное сообщение «ИИ недоступен: …».

### 1.5 Не сырое: надёжность
* Ничего не падает от плохих данных: обрыв сети, пустой ответ, неизвестная команда ИИ, нет пакета, нет
  микрофона — всё обрабатывается, игра идёт дальше, в лог — причина.
* Работа мода в кадре ≤ 1–2 мс; голос, распознавание, сеть, сохранение памяти — в фоне.
* Подробный лог `saliving.txt` (как у коопа): каждый запрос к ИИ (без ключа!), время ответа, распознанный текст,
  выбранный голос, ошибки, расход. Ключ в лог не пишется никогда.
* Сохранение мира/памяти — вместе с игрой и раз в несколько минут; повреждённый файл — откат к прошлому.

## 2. Проверка до отправки (на компьютере)

1. Сборка без ошибок, превью меню «AI» картинками (как у коопа).
2. Цепочка целиком: запись фразы → GigaAM → текст → ИИ (настоящий запрос) → озвучка xVibe → снова GigaAM →
   разборчивость ≥ 85% на одобренных голосах, первая фраза не обрывается.
3. Время: от конца фразы до начала голоса — замер, цель ≤ 2–3 с.
4. Плохие случаи: нет сети, неверный ключ, лимит, пустой пакет, длинный ответ — ничего не падает.
5. Групповая сцена из 3 педов — голоса разные, очередь соблюдается.

## 3. Что делает игрок (тест в одиночку)

Чек-лист придёт вместе с `.so` и пакетом:
мастер первого запуска → поговорить с прохожим → с копом (взятка, задержание) → с бандой (группа) →
звонок по телефону → игра без интернета → «Состояние» → прислать `saliving.txt` (+ видео, если что-то странно).
