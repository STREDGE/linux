# SA Living — живые педы с ИИ (план)

Отдельный мод AML для GTA SA Android 2.10 arm64. Живёт в папке `sa-living/` репозитория SA Coop,
но **с коопом не смешивается**: свой код, своя сборка, свой `.so` (`libSALiving.so`), своя версия.
Общие сторонние библиотеки (AML-заголовки, ImGui, Opus) — из корневой `third_party/`.
Нужный код коопа (микрофон/AAudio, меню, касания, JNI) **копируется** сюда, а не подключается из `src/` коопа.

Статус: **план**, кода ещё нет.

## 1. Главные решения

* **В моде нет ключа API.** Каждый вставляет свой ключ Anthropic в разделе «ИИ». Без ключа работает
  «мозг реализма» (копы, банды, прохожие) — свой код, без интернета.
* **Модель: Claude Haiku 5.5** (`claude-haiku-5-5`), **режим (effort) `low`** — быстро и дёшево.
  Модель выбирается в настройках (можно поставить другую, если игрок захочет).
* **Педы не просто выбирают действие из списка** — они **строят поведение сами** из набора «кирпичиков»
  (см. раздел 4): цепочки действий, свои цели на время, инициатива, память, слухи, сцены с другими педами.
* **Распознавание речи и голос педов — средствами Android** (`SpeechRecognizer`, `TextToSpeech`):
  бесплатно, второй ключ не нужен. Голоса Android проще, чем у платных сервисов; позже можно добавить
  платный голос по желанию (отдельный ключ).
* **Кооп**: разговоры и решения ведёт один телефон (хост), друг получает текст, звук и действия.

## 2. Раздел настроек «ИИ» (в игре)

Кнопка **ИИ** в главном меню и паузе (тот же стиль, что меню CO-OP).

| Пункт | Что делает |
|---|---|
| ИИ-педы: вкл/выкл | без ключа — только «мозг реализма» |
| Ключ Anthropic | **«Вставить из буфера»**, показ замаскированным `sk-ant-…a1b2`, кнопки «Проверить» и «Удалить» |
| Модель | по умолчанию `claude-haiku-5-5` |
| Режим | `low` по умолчанию (можно `medium` — умнее, но медленнее и дороже) |
| Голоса педов / субтитры | вкл/выкл |
| Язык | русский / английский |
| Инициатива педов | как часто педы сами заговаривают/действуют (выкл / редко / часто) — влияет на расход |
| Лимит в день | максимум запросов; дальше педы отвечают простыми фразами без ИИ |
| Расход | сколько запросов и примерно сколько потрачено сегодня/за месяц (по `usage` из ответов) |
| Кнопка «Говорить» | двигается в «Настройка сенсоров», как кнопки коопа |
| Проверка | «Скажи что-нибудь» → распознанный текст + ответ ИИ + голос |

Ключ хранится только в конфиге мода на телефоне, **никогда не пишется в лог**, маскируется при показе.
В меню предупреждение: «не отправляй конфиг другим — там ключ». Голос и текст уходят наружу только
пока зажата «Говорить» (распознавание — сервис Android на телефоне; в Anthropic уходит уже текст).

## 3. Как идёт запрос к Claude

* HTTPS `POST https://api.anthropic.com/v1/messages` через Java (`HttpURLConnection` по JNI) — системные
  сертификаты Android, без OpenSSL в моде. Официального SDK для C++ нет, поэтому — прямой HTTP.
  Заголовки: `x-api-key`, `anthropic-version`, `content-type: application/json`.
* Тело: `model`, `max_tokens` (~1024), `output_config: {effort: "low"}`, `system`, `tools`, `messages`, `stream: true`.
  Потоковый ответ (SSE): пед начинает говорить, как только пришла первая фраза.
* **Кэш подсказки** (`cache_control`): описание мира, правила и список инструментов — неизменные и идут первыми,
  кэшируются; меняющееся (обстановка, реплика) — в конце. Дешевле и быстрее.
* Перед каждым запросом в отдельный поток, игровой поток не ждёт. Ошибки: 401 — «ключ неверный»,
  429/529 — повтор позже, нет сети — пед отвечает простой фразой без ИИ.
* Действия приходят как вызовы инструментов (`tool_use`), каждый ввод проверяется по схеме перед выполнением.
  Если модель вызвала несколько инструментов — выполняются по порядку (цепочка).
* Точные поля API сверяются с документацией Anthropic при написании кода (не по памяти).

Примерный расход на одну реплику педа: ~2–3 тыс. токенов на входе (большая часть из кэша) и ~100–200 на выходе.
По прайсу Haiku 5.5 ($0,10 / $0,50 за 1 млн токенов на входе / выходе) это доли цента за реплику;
точная цифра — в разделе «Расход» после первых тестов.

## 4. Поведение педа — «кирпичики» (инструменты)

ИИ собирает поведение из инструментов, а мод выполняет их средствами игры (задачи педов, анимации,
скриптовые команды). Можно вызывать несколько подряд — получается план.

| Группа | Инструменты |
|---|---|
| Речь | `say(text, emotion, to)` — сказать (CJ, другу, другому педу); `shout` — крикнуть всем рядом |
| Движение | `walk_to / run_to(place или цель)`, `follow(кто, дистанция)`, `flee(от кого)`, `wait(сек)`, `face(кто)`, `sit/lean/lie` |
| Жесты | `animate(имя)` — из каталога анимаций игры по категориям (разговор, угроза, страх, радость, танец, курить, звонить…) |
| Предметы и деньги | `give_money / take_money(сумма)`, `give_item / take_item`, `show_weapon`, `holster` |
| Транспорт | `enter_vehicle(какая, место)`, `drive_to(куда, стиль)`, `exit_vehicle`, `steal_vehicle` |
| Бой | `attack(кто, чем)`, `aim_at(кто)`, `surrender`, `stop_fight` |
| Связь | `call(копы / банда / скорая / другой пед)`, `whistle_gang` — позвать своих рядом |
| Копы | `order(команда)`, `arrest(кто)`, `cuff`, `escort_to_car`, `accept_bribe / refuse_bribe`, `release` |
| Цели | `set_goal(текст, срок, условия)` — долгая цель, которую «мозг реализма» исполняет сам (например «караулить CJ у дома до ночи», «найти того, кто убил брата»); `clear_goal` |
| Память и мир | `remember(факт)`, `relationship(к кому, ±)`, `spread_rumor(текст, район)`, `mark_on_map(место, подпись)` для подсказок CJ |
| Сцены | `involve(других педов рядом, роль)` — позвать друзей, устроить спор, позвать свидетеля |

**Инициатива**: ИИ вызывается не только когда CJ говорит, но и по событиям (с ограничением частоты):
педа толкнули, увидел оружие, убили его друга, CJ вернулся туда, где нахамил, цель из `set_goal` выполнена или
сорвалась. Тогда пед сам решает — заговорить, позвать своих, отомстить, уйти.

**Ограничители** (чтобы не ломать игру): ИИ не может создавать оружие/деньги из воздуха без причины,
не трогает миссии игры, не телепортирует; число вызовов в минуту и одновременно «живых» ИИ-педов ограничено;
все параметры проверяются модом.

### Контекст для ИИ

Кто пед (коп / Grove / Ballas / Vagos / Aztecas / прохожий / бомж / торговец / таксист…), пол, возраст,
характер (генерируется один раз и хранится), район и чья территория, время, погода, розыск CJ, оружие в руках,
одежда/цвета, деньги, репутация CJ в районе и у банды педа, недавние события рядом (убийства, драки, ДТП),
память педа о CJ, слухи района, кто ещё стоит рядом.

## 5. «Мозг реализма» (без ИИ)

### Копы и арест
* Розыск только от **свидетелей** (пед позвонил — видно, как достаёт телефон) или если коп видел сам.
* Сначала приказ: «Стоять! Руки вверх!». Игрок: «Сдаться» (руки вверх), бежать, драться.
* **Сдался**: подходит с оружием → к машине/на землю → обыск (оружие изымается) → наручники → ведут к машине →
  назад → поездка (смотреть или пропустить) → участок → штраф / срок (промотка времени) / конфискация, адвокат.
* **Взятка**: через ИИ (разговор) или по правилам без ИИ: сумма, свидетели, напарник, тяжесть, характер копа.
  Мало или при свидетелях — +звезда «попытка подкупа».
* Побег/сопротивление — жёстче. Мелочи (толкнул, ДТП без жертв) — штраф на месте.

### Банды
Территории, цвета, репутация CJ у каждой банды; свои — здороваются, идут с тобой, просят помочь; чужие на своей
земле — предупреждают → окружают → стреляют; месть за убитых, «крыша», ограбления, сделки.

### Прохожие
Пугаются оружия, звонят в полицию, свидетели запоминают CJ (одежда, машина), слухи по району, характеры,
могут заступиться/драться/снимать на телефон/просить мелочь. Ночью меньше людей и опаснее.

### Прочее
Больница (счёт, потеря вещей), торговцы, такси, память между сохранениями (свой файл рядом с сейвом).

## 6. Анимации

«Руки вверх», прицел копа, жесты разговора — есть в игре. Наручники, «скрутить», «вести под руку» —
нужны свои анимации (загрузка IFP) — отдельный этап; до него — замена ближайшими анимациями игры.
