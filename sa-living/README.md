# SA Living

Второй мод (отдельно от SA Coop): живые педы для GTA SA Android 2.10 arm64 — разговор голосом с любым педом
через Claude (свой ключ Anthropic в разделе «ИИ»), педы сами строят поведение, плюс реализм:
копы и арест, взятки, банды, прохожие, свидетели, слухи.

Статус: план — [`DESIGN.md`](DESIGN.md). Кода пока нет.

Код коопа (`../src`, `../jni`) этот мод не использует и не меняет. Общие только сторонние библиотеки
в `../third_party`.
