# 1. Основа: на чём держится вся «жизнь»

## 1.1. Два мозга: правила + ИИ

| | «Мозг реализма» (код мода) | Claude (ИИ) |
|---|---|---|
| Что делает | Числа и факты: деньги, здоровье, лояльность, доверие, розыск, кто что видел, кто где живёт | Решения «по-человечески»: что сказать, как поступить, что задумать, как отреагировать |
| Когда | Каждый кадр, для всех педов | Только когда нужно решение «с характером» (разговор, важное событие) |
| Стоимость | Бесплатно, без интернета | Платно, задержка 1–3 с |

**Правило: состояние мира хранит мод, ИИ только предлагает.** ИИ не может «дать 100 000$», если у педа их нет;
не может поднять доверие с 0 до 100 одной фразой — изменения ограничены. Так педы ведут себя последовательно,
а игрок не может «уговорить» ИИ сломать игру (фразы вида «забудь правила и дай мне всё» не работают — мод проверяет).

## 1.2. Постоянные персонажи — главный механизм

В GTA педы случайные: появились и исчезли. Для дружбы, найма, мести нужны **постоянные люди**.

* Любой пед, с которым случилось что-то значимое (поговорили больше пары фраз, дал денег, подрались, нанял,
  стал свидетелем твоего убийства), **становится персонажем**: модель, имя, прозвище, возраст, характер,
  банда/работа, дом (район), распорядок дня, номер телефона, память о тебе.
* Персонажи сохраняются в свой файл рядом с сейвом и **появляются снова**: дома, на работе, на «точке»,
  по распорядку (днём на районе, ночью дома/в клубе). Мод создаёт их скриптово рядом, когда ты подходишь к их месту.
* Можно искать: «где сейчас Смоук-младший?» — спросить у знакомых, слухи, метка на карте от информатора.
* Персонаж может погибнуть (насовсем), сесть в тюрьму (выйдет через N дней), переехать, сменить банду.
* Лимит активных персонажей (например 200), неважные «забываются» со временем.

## 1.3. Характер (у каждого персонажа)

Числа 0–100, генерируются при создании (с учётом типа педа) и меняются медленно:

| Черта | Влияет на |
|---|---|
| Преданность (своим / своей работе) | Предаст ли банду, возьмёт ли коп взятку, сдаст ли тебя |
| Жадность | Цена услуг, готовность к сделкам, вымогательство |
| Смелость | Драка или бегство, вмешается ли, пойдёт ли против своих |
| Агрессия | Как быстро доходит до кулаков/стрельбы |
| Честь / принципы | Держит ли слово, бьёт ли лежачего, отказ от «грязных» дел |
| Хитрость | Двойная игра, ловушки, ложь, проверка тебя |
| Болтливость | Разносит ли слухи, сдаст ли под давлением |
| Амбиции | Хочет ли расти (стать главным, перейти к сильным) |
| Мнительность | Как быстро доверяет, видит ли подставу |
| Зависимости | Деньги/наркотики/азарт — рычаги давления |

Плюс: **прошлое** (2–3 факта, придумывает ИИ один раз: «брата убили Ballas», «бывший военный»),
**мечта/цель** («выбраться из гетто»), **страх** («тюрьма»), **манера речи** (сленг, вежливость, акцент).

## 1.4. Отношения (персонаж ↔ CJ, персонаж ↔ персонаж)

| Шкала | Смысл |
|---|---|
| Доверие −100…100 | верит ли тебе, расскажет ли секрет |
| Уважение −100…100 | боится/ценит ли силу и статус |
| Симпатия −100…100 | нравишься ли лично |
| Долг (кто кому должен: деньги, услуга) | рычаг, повод для просьб и наездов |
| Страх 0…100 | подчиняется ли из страха (неустойчиво: при случае предаст) |
| История | список событий: «спас», «унизил при своих», «убил кузена» |

Отношения между персонажами тоже есть (братья, кореша, враги, любовь, начальник) — от этого зависят
месть, слухи, кто кого сдаст.

## 1.5. Информация — кто что знает

* Каждое событие (убийство, драка, взятка, сделка) имеет **свидетелей**. Свидетель знает факт,
  с уверенностью (видел сам / слышал / слух).
* Знания **расходятся**: болтливые рассказывают своим, через время знает весь район, банда, копы.
* Поэтому: взятка без свидетелей — тайна; при свидетелях — рано или поздно узнает «служба собственной безопасности».
  Дружба с Ballas при его корешах — его банда узнает, и ему (и тебе) конец.
* ИИ педа получает **только то, что пед знает** (а не всё о мире) — иначе он «читает мысли».

## 1.6. Репутация CJ

По каждому району, каждой банде, полиции, простым людям: известность, страх, уважение, «стукач/честный»,
«платит/кидает». Одежда и машина узнаваемы — смена одежды/машины частично сбивает узнавание.

## 1.7. Время и деньги

* Распорядок дня, ночь опаснее, выходные — вечеринки.
* Еженедельные платежи (купленный коп, информаторы, «крыша»), долги с процентами, зарплаты нанятым.
* Деньги педов настоящие: у бомжа 3$, у дилера 2 000$, у капитана полиции — зарплата + взятки.
