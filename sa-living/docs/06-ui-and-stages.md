# 6. Интерфейс и этапы

## 6.1. На экране

| Элемент | Что делает |
|---|---|
| Кнопка «Говорить» | зажал — говоришь с ближайшим персонажем (или по телефону) |
| Подсветка собеседника | кому ты говоришь (ближайший в поле зрения); свайп — сменить |
| Субтитры | реплики CJ и педа, имя/прозвище, эмоция |
| Быстрые действия во время разговора | «Дать денег» (своя клавиатура суммы), «Показать ствол», «Уйти», «Сдаться» |
| Карточка персонажа | имя, банда, отношения (доверие/уважение/симпатия), что о нём знаешь |
| Телефон | контакты, звонки, SMS, «пока тебя не было» |
| Уведомления | слухи, звонки, «тебя ищут Ballas», «свой коп предупреждает» |

Все элементы двигаются в «Настройка сенсоров» игры (как в коопе).

## 6.2. Раздел «ИИ» в меню

Ключ (вставить/проверить/удалить), модель, effort, голоса/субтитры, язык, инициатива педов, лимиты,
расход, журнал разговоров, сброс памяти мира (новая жизнь города).

## 6.3. Этапы

| # | Этап | Что проверяем |
|---|---|---|
| 1 | Раздел «ИИ», ключ, проверка; кнопка «Говорить»; распознавание и голос Android | ключ работает, пед отвечает голосом |
| 2 | Персонажи: создание, характер, память, сохранение, повторное появление | пед помнит тебя через день |
| 3 | Инструменты: речь, движение, жесты, деньги, драка, звонок своим | пед сам строит поведение |
| 4 | Информация: свидетели, слухи, репутация | новости расходятся |
| 5 | Полиция: розыск по свидетелям, задержание по шагам, участок, суд, взятки | весь арест |
| 6 | Связи в полиции: наём, услуги по телефону, риски, ССБ | свой коп |
| 7 | Банды: отношения, дружба с чужими, информаторы, двойная игра, переход, войны, переговоры | пример с Ballas |
| 8 | Город: телефон, распорядок, режиссёр, «пока тебя не было» (Batches) | город живёт |
| 9 | Свои анимации (наручники, скрутить, вести) | реализм ареста |
| 10 | Кооп: ИИ на хосте | вдвоём |

Каждый этап — рабочая версия, которую можно ставить и проверять.
