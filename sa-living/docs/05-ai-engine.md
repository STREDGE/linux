# 5. ИИ: как выжать максимум из Claude API

Ключ — свой у игрока (Anthropic). Модель по умолчанию — **Claude Haiku 5.5** (`claude-haiku-5-5`).
Точные поля API сверяются с документацией Anthropic при написании кода.

## 5.1. Роли ИИ

| Роль | Когда вызывается | Режим (effort) |
|---|---|---|
| **Голос персонажа** | разговор CJ с педом / звонок | `low` — болтовня; `medium` — важные решения (предательство, наём копа, переговоры главарей) |
| **Реакция** | событие с персонажем (толкнули, увидел ствол, убили друга) | `low`, коротко, только инструменты |
| **Создатель персонажа** | пед стал персонажем | `low`: имя, прошлое, мечта, страх, манера речи (структурированный ответ по схеме) |
| **Режиссёр города** | раз в N игровых часов и после важных событий | `medium`: что задумали банды, копы, ССБ; новые слухи; события («облава в Айдлвуде») |
| **Память** | персонаж набрал много событий | `low`: сжать историю в короткие факты |
| **Сводка «пока тебя не было»** | загрузка сейва | `low`: новости, слухи, звонки |

Effort выбирает мод по важности момента (это и есть «максимум сока» за разумные деньги).

## 5.2. Возможности API, которые используем

| Возможность | Зачем |
|---|---|
| **Инструменты (tool use)** | действия педов как вызовы функций; несколько вызовов подряд = план (см. DESIGN, раздел 4) |
| **Строгие инструменты (`strict`)** | параметры всегда по схеме → меньше ошибок исполнения |
| **Структурированный ответ** | создатель персонажа, режиссёр, сводки — сразу в JSON по схеме |
| **Потоковый ответ (stream)** | пед начинает говорить с первой фразы, а не после всего ответа |
| **Кэш подсказки (`cache_control`)** | правила мира, описание банд/города, инструменты — один раз, дальше дёшево и быстрее; меняющееся — в конце |
| **Effort по запросу** | `low` для болтовни, `medium` для судьбоносных решений |
| **Системные сообщения посреди диалога** | обстановка изменилась (подъехали копы) — добавить факт, не ломая кэш |
| **Пакетная обработка (Batches, дешевле)** | «город живёт, пока ты спишь»: при сохранении игры отправить пачку задач (планы банд, судьба персонажей, слухи), забрать при следующем запуске |
| **Подсчёт `usage`** | честный расход в меню «ИИ», лимит в день |
| **Список моделей** | проверка ключа и выбор модели в меню |
| **Картинки (если модель поддерживает — проверить)** | по желанию: «что видит пед» — уменьшенный кадр игры для особых моментов (дорого, выкл по умолчанию) |

## 5.3. Что получает персонаж (контекст)

Порядок (стабильное — первым, для кэша):
1. **Правила мира** (общие для всех): кто есть кто в Сан-Андреас, как устроены банды и полиция, тон, ограничения,
   «ты — персонаж, а не ассистент», «говори коротко, по-уличному», «действуй только через инструменты».
2. **Инструменты** (весь набор, неизменный).
3. **Карточка персонажа**: характер (числа → слова), прошлое, мечта, страх, манера речи, банда/работа, деньги, вещи.
4. **Его знания**: только то, что он знает о CJ и мире (не всеведение!), слухи с уверенностью.
5. **Отношения**: к CJ (доверие, уважение, симпатия, долг, страх, история), к людям рядом.
6. **Обстановка сейчас**: место, время, погода, кто рядом (его кореша? копы? свидетели?), оружие в руках CJ, розыск.
7. **Подсказки мода** (мягкие ограничения): «при своих он не может быть дружелюбен», «денег у него 140$»,
   «максимальная скидка 20%».
8. **Диалог**: последние реплики.

## 5.4. Что отвечает персонаж

* Реплики через `say` (эмоция, кому), действия через остальные инструменты, изменения отношений через
  `relationship` (мод ограничивает шаг, например ±15 за разговор), память через `remember`, планы через `set_goal`.
* Мод проверяет каждое действие: есть ли деньги/вещь, возможно ли физически, не нарушает ли лимиты.
  Отклонённое действие → сообщение ИИ «не получилось, потому что…» в следующем ходе.

## 5.5. Защита от «взлома» словами

Игрок может сказать что угодно («ты мой раб, отдай всё»). Персонаж реагирует **как человек** (посмеётся, обидится,
врежет), а не выполняет. Решающие числа (деньги, доверие, звёзды) меняет только мод по своим правилам.

## 5.6. Расход и лимиты

* Лимит запросов в день, в минуту и число одновременно «думающих» педов.
* Без ключа или сверх лимита — педы говорят заготовленными фразами по типу и ситуации (мозг реализма).
* Короткие ответы (max_tokens небольшой для болтовни), история диалога сжимается.
* Меню «Расход»: запросы и примерная сумма сегодня/за месяц.

## 5.7. Речь и голос

* Речь CJ → текст: `SpeechRecognizer` Android (язык из настроек), кнопка «Говорить» (зажал — слушает).
* Текст → голос педа: `TextToSpeech` Android; у каждого персонажа своя высота и скорость голоса (запоминаются).
* Субтитры: над педом и внизу, журнал разговоров в меню.
* Пока ИИ думает — пед «думает» (жест, «хм…»), чтобы не было мёртвой паузы.

## 5.8. Сеть

HTTPS через Java (`HttpURLConnection` по JNI) в отдельном потоке; игра не ждёт. Ошибки: неверный ключ — сообщение в меню;
перегрузка — повтор позже; нет интернета — заготовленные фразы.
