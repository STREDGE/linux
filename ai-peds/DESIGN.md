# SA Living — живые педы с ИИ (план отдельного мода)

Отдельный мод AML для GTA SA Android 2.10 arm64 (рядом с SA Coop, свой `.so`).
Статус: **план**, кода ещё нет. Общий код с коопом (голос, интерфейс, касания, JNI) переиспользуется.

## 1. Главные решения

* **В моде нет ключа API.** Каждый игрок вставляет свой ключ в разделе настроек «ИИ».
  Без ключа мод работает: весь «реализм» (копы, банды, прохожие) — свой код, без интернета.
  С ключом — можно разговаривать с педами голосом.
* **Нейросеть не управляет педами каждый кадр.** Два слоя:
  1. «Мозг реализма» — правила, характеры, память, свидетели. Для всех педов, бесплатно, без задержки.
  2. ИИ — только для того, с кем идёт разговор. Отвечает фразой + эмоцией + **действием из фиксированного списка**,
     которое выполняет мод средствами игры.
* **Совместимость с коопом**: разговоры и решения ИИ ведёт один телефон (хост), друг получает результат
  (текст, звук, действие) по сети коопа.

## 2. Раздел настроек «ИИ» (в игре)

Кнопка **ИИ** в главном меню и паузе (как CO-OP), тот же стиль меню.

| Пункт | Что делает |
|---|---|
| ИИ-педы: вкл/выкл | без ключа — только «мозг реализма» |
| Сервис | готовые наборы: **«Всё через OpenAI»**, **«Всё через Google Gemini»**, **«Своя настройка»** (отдельно распознавание / нейросеть / голос) |
| Ключ | **«Вставить из буфера»** (печатать длинный ключ в игре неудобно), показывается замаскированным `sk-…a1b2`, кнопки «Проверить» и «Удалить» |
| Адрес API (своя настройка) | для любых OpenAI-совместимых сервисов (OpenRouter, Groq, DeepSeek, свой сервер) |
| Модель | список, подгружается после проверки ключа; по умолчанию — быстрая и дешёвая |
| Голоса педов | вкл/выкл; если выкл — только субтитры (дешевле) |
| Субтитры | вкл/выкл |
| Язык | русский / английский (речь игрока и ответы) |
| Лимит | максимум разговоров в день / примерная сумма в день — дальше педы отвечают коротко без ИИ |
| Как начать разговор | своя кнопка «Говорить» (двигается в «Настройка сенсоров», как кнопки коопа) |
| Проверка | «Скажи что-нибудь» → показать распознанный текст и ответ — проверить ключ, микрофон и голос |

Ключ:
* хранится только на телефоне в конфиге мода (`Android/data/<игра>/configs/<мод>.ini`), **никогда не пишется в лог**;
* при показе маскируется;
* предупреждение в меню: «не отправляй свой конфиг другим — там ключ».

Голос игрока уходит в выбранный сервис только пока зажата кнопка «Говорить».

## 3. Разговор с педом

1. Игрок подходит (≤ 4 м, пед в поле зрения) и зажимает «Говорить». Пед останавливается и поворачивается.
   Ближайший подходящий пед подсвечивается.
2. Голос → текст (распознавание).
3. Запрос к нейросети: описание педа + обстановка + память + история разговора + реплика игрока.
4. Ответ строго в формате JSON:
   ```json
   { "say": "Ты чё, с Гроув? Вали отсюда.", "emotion": "angry",
     "action": "threaten", "params": { "weapon": "show" }, "remember": "CJ нагрубил у ларька" }
   ```
5. Текст → голос (мужской/женский, возраст — по модели педа; голос закрепляется за педом).
6. Пока говорит — жесты (анимации разговора игры), субтитры над головой/внизу.
7. Мод выполняет `action`.

Ожидаемая задержка — 1,5–3 с. Пока ждём — пед «думает» (жест, «эээ…»), чтобы не было мёртвой паузы.

### Контекст для ИИ

Кто пед (коп / Grove / Ballas / Vagos / Aztecas / прохожий / бомж / торговец / проститутка / таксист…),
пол, возраст, характер (генерируется один раз: трус, драчун, жадный, честный, болтун, пьяный…),
район и чья территория, время, погода, розыск игрока, оружие в руках, деньги, одежда/цвета,
репутация CJ в районе и у банды педа, что CJ сделал рядом за последние минуты (убийства, драки, ДТП),
память этого педа о CJ, слухи района.

### Действия (список, из которого выбирает ИИ)

Говорить и стоять · уйти · убежать · пойти за CJ · ждать здесь · напасть (кулаки / оружие) · достать оружие
и угрожать · позвать копов (звонок) · позвать своих (банда) · отдать деньги · взять деньги (взятка/плата) ·
продать (оружие, наркотики, еду) · сесть в машину CJ · выйти из машины · показать дорогу (метка на карте) ·
дать задание · принять/отклонить взятку · арестовать · отпустить.

## 4. «Мозг реализма» (без ИИ)

### Копы и арест
* Розыск появляется только от **свидетелей**: кто-то увидел и позвонил (видно, как достаёт телефон),
  или коп увидел сам. Убил тихо без свидетелей — звёзд нет.
* Сначала команда: «Стоять! Руки вверх!». Выбор игрока: поднять руки (кнопка «Сдаться»), бежать, драться.
* **Сдался**: коп подходит с оружием → лицом к машине/на землю → обыск (оружие изымается) → наручники →
  ведут к машине → посадка назад → поездка (можно смотреть или пропустить) → участок → оформление:
  штраф / срок (промотка времени, день/ночь меняются) / конфискация. Можно позвонить адвокату (дорого, меньше срок).
* **Взятка**: в разговоре с копом (ИИ) или без ИИ — по правилам. Учитывается сумма, свидетели, напарник,
  тяжесть преступления, характер копа. Мало или при свидетелях — +звезда «попытка подкупа».
* Побег из машины / сопротивление — розыск выше, копы жёстче (оружие сразу).
* Мелкое (толкнул, ДТП без жертв) — штраф на месте, без ареста.
* Аварии, светофоры, скорость — по желанию, позже.

### Банды
* Территории и цвета, **репутация CJ у каждой банды** (уважение/вражда).
* Свои: здороваются, идут с тобой, просят помочь, предупреждают об опасности.
* Чужие на своей территории: предупреждают → окружают → стреляют. Красная одежда в районе Grove — тоже повод.
* Помнят убитых своих (месть, засады), «крыша» для магазинов, ограбления, сделки.

### Прохожие
* Видят оружие в руке — пугаются, уходят, кто-то звонит в полицию.
* Свидетели запоминают CJ (одежда, машина); по району расходятся **слухи** — через время узнают и другие.
* Характер у каждого; могут заступиться, драться, снимать на телефон, просить мелочь.
* Ночью меньше людей и опаснее, днём — наоборот.

### Прочее
Больница (счёт за лечение, потеря вещей), торговцы, такси, память между сохранениями (свой файл рядом с сейвом).

## 5. Техника

* **Интернет**: запросы HTTPS через Java (`HttpURLConnection` по JNI) — системные сертификаты Android,
  не тащим OpenSSL. Потоковые ответы (SSE), чтобы пед начинал говорить раньше.
* **Распознавание**: OpenAI-совместимый `/audio/transcriptions` (Whisper и аналоги) или Gemini.
* **Нейросеть**: OpenAI-совместимый `/chat/completions`, Anthropic Messages, Google Gemini — через общий интерфейс.
* **Голос педа**: OpenAI TTS, Gemini TTS, ElevenLabs (по желанию). Воспроизведение — AAudio (из коопа).
* **Микрофон**: модуль голоса из SA Coop (AAudio, 48 кГц).
* **Анимации**: «руки вверх», прицел копа, жесты разговора есть в игре. Наручники, «скрутить», «вести под руку» —
  нужно добавить свои анимации (загрузка IFP) — отдельный этап.
* **Действия педов**: задачи игры (`CTask…`) и скриптовые команды — то же, что делают миссии.

## 6. Этапы

1. **Разговор**: раздел «ИИ», ключ из буфера, «Проверка»; подошёл → сказал → пед ответил голосом и субтитрами.
2. **Действия** по ответу ИИ + характеры + память педа.
3. **Арест** полностью (без своих анимаций, потом с ними), взятки.
4. **Банды**: территории, репутация, реакции.
5. **Прохожие**: свидетели, звонки, слухи.
6. Свои анимации (наручники, скрутить, вести).
7. Кооп: ИИ на хосте, синхронизация разговоров и действий.

## 7. Открытые вопросы

* Очерёдность с коопом (машины, оружие, полиция, миссии).
* Каким сервисом и ключом будет проверять сам игрок (нужен свой ключ для теста этапа 1).
