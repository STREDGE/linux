# SA Coop

Кооперативный режим для **GTA San Andreas Android 2.10 (64-bit)** на базе **AML 1.4.0**.
Цель — проходить сюжетные миссии и играть в свободном режиме вдвоём через интернет.

## Возможности (план)

| Этап | Что даёт | Статус |
|---|---|---|
| 0 | Диагностический мод: загрузка, поиск функций игры, конфиг | ✅ готов к тесту |
| 0.5 | Тест связи между телефонами (пинг, потери) через Tailscale | ✅ готов к тесту |
| 1 | Сеть, второй CJ на карте, метка друга на радаре | ⏳ |
| 2 | Машины: водитель + пассажир, стрельба из машины | ⏳ |
| 3 | Оружие, урон, смерть/возрождение, интерьеры, огонь по своим (переключатель) | ⏳ |
| 4 | Полиция и общий уровень розыска (второй CJ как игрок 2) | ⏳ |
| 5 | Синхронизация NPC и транспорта вокруг игроков | ⏳ |
| 6 | Миссии (ведёт хост, друг видит врагов/метки/тексты) | ⏳ |

## Архитектура

- **Хост** запускает миссии и сохраняет прогресс. **Клиент** (друг) играет своим CJ,
  объекты миссий получает от хоста.
- Каждой машиной/NPC управляет один телефон (ближайший игрок), второй показывает копию.
- Связь: UDP. Для игры через интернет (Бельгия ↔ Турция) — Tailscale
  или собственный сервер-посредник.

## Сборка

Собирается автоматически в GitHub Actions при каждом push
(вкладка **Actions → Build SA Coop → Artifacts → `libSACoop-arm64`**).

Локально (нужен Android NDK):

```sh
$NDK/ndk-build NDK_PROJECT_PATH=. APP_BUILD_SCRIPT=jni/Android.mk NDK_APPLICATION_MK=jni/Application.mk
```

## Установка

1. Скопировать `libSACoop.so` в папку модов AML (обычно
   `Android/data/<пакет игры>/mods/`).
2. Запустить игру.
3. Лог: `/sdcard/Documents/AMLModLogs/` или `adb logcat -s SACoop AML`.

## Тест связи (этап 0.5)

1. Оба ставят **Tailscale** (Google Play), входят в **один и тот же** аккаунт, включают.
2. Оба кладут `libSACoop.so` в папку `mods` и один раз запускают игру — появится конфиг
   `Android/data/com.rockstargames.gtasa/configs/net.sacoop.mod.ini`.
3. В конфиге:
   - у хоста: `Role = host`
   - у друга: `Role = client`, `HostAddress = <адрес хоста в Tailscale, 100.x.x.x>`
   - `Port = 7777` у обоих
4. Хост запускает игру первым, потом друг.
5. Результат — в `Documents/AMLModLogs/net.sacoop.mod/sacoop.txt`:
   `Есть связь с хостом! Пинг NN мс` и раз в 10 сек — средний пинг и потери.
