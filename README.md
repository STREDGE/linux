# SkinForge SA

Приложение для Android, которое переносит внешний вид персонажа с картинки на скин
для GTA San Andreas. Работает бесплатно и полностью на телефоне, без интернета.

Готовый APK: [`dist/SkinForgeSA.apk`](dist/SkinForgeSA.apk) (Android 5.0 и новее).

## Замена Си-Джея в один шаг

1. Выберите картинку персонажа.
2. Нажмите «Заменить Си-Джея: выбрать папку texdb» и укажите папку (или её копию),
   в которой лежат `player.img` и папка `player`.
3. Нажмите «Заменить Си-Джея». Рядом появится папка `SkinForge_CJ/player` —
   скопируйте её в `Android/data/com.rockstargames.gtasa/files/texdb/` с заменой.

Приложение перекрашивает голову, тело и стартовую одежду Си-Джея (майку, джинсы, кроссовки)
и само записывает их в кэш текстур игры (`player.txt`, `player.*.dat/.toc/.tmb`).

## Свой скин: как это работает

1. Вы выбираете картинку персонажа — лучше всего развёртку в полный рост
   (спереди, сбоку, сзади), но хватит и одного вида спереди.
2. Вы выбираете базовый скин — любой файл `.dff` для GTA SA. Он даёт фигуру и анимацию.
3. Приложение проецирует картинку на модель и рисует новую текстуру.
4. На выходе папка с файлами мода: `.dff`, `.txd`, текстуры `.png` и инструкция.

Приложение не создаёт новую 3D-модель: фигура остаётся от базового скина,
меняется только раскраска. Поэтому базовый скин стоит брать похожий на персонажа.

## Сборка

```
apt-get install aapt apksigner zipalign dalvik-exchange android-sdk-platform-23
./build.sh
```

Проверка ядра на компьютере, без телефона:

```
javac -d build/test app/src/main/java/com/skinforge/core/*.java tools/DesktopTest.java
java -cp build/test DesktopTest картинка.png папка_результата [модель.dff]
```

## Устройство

- `app/src/main/java/com/skinforge/core` — чтение DFF и IMG, проекция, запись TXD и кэша texdb (чистая Java).
- `app/src/main/java/com/skinforge/app` — экран приложения и редактор рамок.
- `signing/debug.keystore` — отладочный ключ подписи (пароль `android`), лежит в репозитории,
  чтобы новые сборки ставились поверх старых.
