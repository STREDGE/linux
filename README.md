# SA Coop

Кооперативный режим для **GTA San Andreas Android 2.10 (64-bit)** на базе **AML 1.4.0**.
Цель — играть вдвоём через интернет: бегать, ездить, стрелять по всей карте, потом — проходить миссии.

Текущая версия: **0.8.0** (сетевой протокол 9). Готовый мод — `release/libSACoop.so`.

## Установка

1. `release/libSACoop.so` — в папку модов AML (обычно `Android/data/com.rockstargames.gtasa/mods/`).
   Рядом должен лежать **SAUtils** (`libSAUtils64.so`, 1.6+) — через него добавляется кнопка CO-OP.
2. Для голоса в APK должно быть разрешение `RECORD_AUDIO` (см. `docs/handoff/apk-microphone.md`), Android 8+.
3. У обоих игроков — **одна и та же версия** мода (иначе в логе: «у друга другая версия мода»).

## Игра вдвоём

1. Оба: Tailscale включён, в одной сети.
2. Хост: главное меню или пауза → **CO-OP** → «Хост» → скопировать свой адрес `100.x.x.x`, отправить другу.
3. Друг: **CO-OP** → «Подключиться» → вставить адрес → применить.
4. У хоста всплывает запрос с ником друга — «Принять». Повторное подключение того же друга в течение 5 минут — без вопроса.
5. Микрофон: зажми круглую кнопку на экране и говори.
6. Сдвинуть/увеличить кнопку микрофона, панель команды и т.д.: Настройки → Управление → **Настройка сенсоров**
   (там же, где кнопки игры). «Сохранить» / «Отмена» — как для кнопок игры.

## Логи

`Documents/AMLModLogs/net.sacoop.mod/sacoop.txt` (прошлый запуск — `sacoop_prev.txt`, там же запись о вылете).
Строки с `[ХОСТ]`, `[КЛИЕНТ]`, `[ГОЛОС]` — сеть и голос. Раз в 15 с — строка «Статус».

## Сборка

```sh
$NDK/ndk-build NDK_PROJECT_PATH=. APP_BUILD_SCRIPT=jni/Android.mk NDK_APPLICATION_MK=jni/Application.mk -j8
# результат: libs/arm64-v8a/libSACoop.so
```

GitHub Actions (`.github/workflows/build.yml`) собирает при каждом push → Artifacts → `libSACoop-arm64`.

## Структура

```
src/main.cpp        вход мода (AML): проверка символов, папка SA/cleo, запуск модулей, запись о вылете
src/settings.*      конфиг AML net.sacoop.mod.ini: режим, адрес, ник, раскладка
src/coop/           второй CJ: появление/удаление, движение, эхо-режим, перехваты игры
src/net/            UDP-сессия и протокол (рукопожатие, состояние игрока, голос)
src/voice/          голосовой чат: AAudio (dlopen) + Opus, буфер против рывков сети
src/ui/overlay.*    своё меню CO-OP и всё, что рисуется поверх игры; редактор раскладки
src/ui/imgui_rw.*   отрисовка Dear ImGui через RenderWare (Im2D) игры
src/ui/menu.cpp     запасная простая вкладка в настройках (SAUtils), если своё меню не запустилось
src/ui/fonts_data.h шрифты, вшитые в мод (tools/embed_fonts.py)
src/platform/       Android: адрес Tailscale, буфер обмена, разрешения, модель телефона (JNI)
src/game/gta.*      адреса функций и смещения полей libGTASA 2.10 arm64
jni/                ndk-build: Android.mk (мод), opus.mk (статическая libopus)
third_party/        AML (mod/), SAUtils, Dear ImGui 1.90.9, Opus 1.5.2, шрифты (OFL)
tools/preview/      превью меню и интерфейса на компьютере → картинки .ppm
tools/embed_fonts.py урезает шрифты до латиницы+кириллицы и вшивает в fonts_data.h
release/            готовая сборка для игрока + README.txt с версией
docs/               документация
```
