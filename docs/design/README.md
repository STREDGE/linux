# Дизайн SA Coop

`coop-menu.html` — интерактивный макет (открыть в браузере):

- меню Co-op: режимы (выкл / тест в одиночку / хост / подключиться), адрес Tailscale
  с копированием, ввод адреса хоста с цифровой клавиатурой, тумблер «огонь по своим»;
- во время игры: запрос «кто-то подключается» с таймером и кнопками «Принять / Отклонить»,
  плашки «подключился / отключился», полоска «друг говорит», кнопка микрофона
  (зажми и говори) рядом с кулаком, панель «Команда» слева под радаром
  (ник, здоровье, броня, пинг, расстояние, значок «говорит»).

Опубликованная версия: https://claude.ai/artifact/BukWTfrEDpbZ2x2kLZB6Rr (приватная).

Цвета: ночь `#07090d`, панель `#0f141b`, зелёный Grove Street `#4fd15a`, золото `#f2c14e`,
красный `#ff4d4d`. Шрифты макета: Russo One (заголовки), Rubik (текст), JetBrains Mono (цифры).
