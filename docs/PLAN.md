# SA Coop — план (согласован с игроком 2026-11-25)

Игрок хочет **всё сразу, одним большим выпуском**: «чтобы было без лагов и чтобы мы видели, стреляли и
взаимодействовали с одинаковыми объектами». Ниже — что входит и как устроено. Отмечать сделанное здесь.

**Главный принцип (слова игрока): «кооп — как соло-игра, только с другом: всё равноправно, весело, интерактивно».**
Любая механика одиночной игры должна работать для обоих одинаково — проверять каждую по этому правилу.

Основа решений: **хост — хозяин мира.** У клиента своего населения нет: всё, что вокруг (педы, машины,
копы, банды, время, погода, миссии), — копии с телефона хоста. Клиент управляет только своим CJ и тем,
за руль чего он сел.

## 1. Починка по диагностике 0.8.7 (тест с другом 25.11)
- [x] Время пакета сравнивать через `Since` (сейчас «минус» → огромное число → второй CJ пересоздавался 33 раза/с).
- [x] Задачу «сесть» второму CJ давать один раз; перед посадкой проверять, что анимации машины загружены
      (вылет в `CVehicleAnimGroup::ComputeAnimDoorOffsets`).
- [x] Новый второй CJ сразу в правильном интерьере (сейчас первые кадры — интерьер 14, невидим).
- [x] «Поводок» режима на двоих: дальше ~60 м друг от друга CJ переставал двигаться —
      `CGameLogic::IsPlayerAllowedToGoInThisDirection` (перехват: всегда «можно»).

## 2. Экран загрузки при подключении
- [x] Когда друг подключается — экран «Загрузка мира NN %» поверх игры (у клиента), с этапами (0.9.0):
      соединение → мир хоста (время, погода, розыск) → перенос к хосту → модели вокруг → люди и машины → готово.
- [ ] У хоста в это время — плашка «<ник> загружается NN %».
- [ ] Пока идёт загрузка, клиент не управляет CJ и не виден хосту.

## 3. Один мир на двоих
- [x] Время суток и погода — как у хоста (раз в 2 с; `CClock`, `CWeather`).
- [x] Клиент при подключении появляется рядом с хостом (0.9.0).
- [x] «Подключиться» из главного меню — сразу в мир хоста (его сохранение передаётся и загружается) (0.9.0).
- [x] Пауза / сворачивание игры не рвут связь: игрок «замирает», связь держится до 60 с.
- [x] Арест и больница: у друга его CJ исчезает и появляется у участка/больницы.
- [ ] Деньги — у каждого свои.
- [x] Розыск: хост выбирает в меню — общий на двоих или у каждого свой (0.8.9).

## 4. Одинаковые люди и машины вокруг (население)
- [x] У клиента выключено своё население (педы, трафик, припаркованные машины, копы):
      плотность 0, свои случайные — удалить при подключении.
- [x] Хост шлёт педов в радиусе ~120 м от клиента: номер, модель, позиция, курс, скорость, что делает
      (идёт/бежит/стоит/дерётся/убегает/целится/лежит), оружие, здоровье. 10 раз/с, ближние чаще.
- [x] Хост шлёт машины вокруг клиента (обобщение общих машин 0.8): модель, цвета, водитель-пед, состояние.
- [x] Клиент создаёт копии и ведёт их плавно (интерполяция ~100 мс + экстраполяция), анимации — задачами игры.
- [x] Клиент бьёт/стреляет/давит копию → событие хосту → хост применяет урон у себя → результат (ранен, убит,
      убегает, нападает в ответ) приходит обратно. Так оба видят одно и то же.
- [x] Угон машины с водителем-педом у клиента → хост выкидывает педа у себя, машина становится общей.
- [x] Банды и прохожие относятся ко второму CJ как к тебе (отношения PLAYER2 = PLAYER1) (0.9.1).
- [x] Копы, банды, драки, свидетели — педы хоста, видят обоих игроков (цели — оба CJ): копы хоста
      гоняются и стреляют по другу, если у него розыск; банды нападают / помогают обоим; друга не «забывают».
- [x] Полиция при **общем розыске** ловит обоих: погоня, стрельба, арест (скрутили → машина → участок)
      для каждого, и оба это видят; урон копов по другу честно доходит до него.
      При **своём розыске** — гонятся только за тем, у кого звёзды.
- [x] Вербовать Grove в банду может каждый; банда помогает своему лидеру.
- [x] Почему не «по-быстрому»: заставить копов хоста стрелять в отражение друга нельзя — у хоста его ранить
      может только телефон друга, вышли бы копы, бесконечно стреляющие в неуязвимого. Только через общих педов.
- [x] Лимиты против лагов: до ~40 педов и ~30 машин, приоритет ближних и видимых, сжатые пакеты.

## 5. Миссии вместе
- [x] Миссии ведёт хост; маркеры миссий у клиента спрятаны (у клиента скрипты миссий не запускаются).
- [x] Катсцена у хоста → у клиента та же катсцена (по имени), пропускает хост; после — клиент рядом с хостом.
- [x] Миссия начинается в машине → второго CJ сразу на свободное место; места заняты педами миссии → один пед
      невидим и остаётся в машине (скрипт не ломается), друг на его месте; пед появляется, когда все вышли / катсцена.
- [x] Педы, машины, метки, тексты, таймеры миссии — копии с хоста (через население п.4 + метки/тексты).
- [x] Провал / успех видят оба.

## 8. Мини-сервер у хоста (пожелание игрока 25.11, выпуск 1.0.0)
- [x] Встроенный Tailscale (не приложение, а его механика внутри мода; `tsbridge/` на Go, вшит в мод).
      Разрешение «как VPN» не нужно: сеть только для игры (userspace). Вход в аккаунт Tailscale — один раз,
      браузер открывается сам.
- [x] ID точки (6 цифр) создаётся сам при первом запуске; хост «Открыть точку», друг вводит ID → «Подключиться».
- [x] Лобби: оба видят друг друга; хост выбирает, во что играть: текущая игра / кооп-сохранение из папки /
      файл с телефона (системное окно «Файлы») → «Запуск» → оба загружаются (у друга экран с %).
- [x] Одиночные и кооп-сохранения раздельно: в кооп-мире все ячейки игры — файлы `SACoop_N.b`; копия каждого
      сохранения — в папке `SA/SACoop/Сохранения` (видна в «Файлах» телефона), там же файлы для лобби.
- [ ] Проверить на телефонах: вход в Tailscale, поиск точки по ID, мост, лобби, выбор файла.

## Как проверяем
Каждая сборка: тест в одиночку («Тест») + игра с другом, логи `sacoop.txt` с обоих телефонов + видео
с обоих экранов. Подробный лог уже пишет всё (см. `docs/ARCHITECTURE.md` §4а «Подробный лог»).
Первая сборка «всё сразу» будет сырой — чиним по логам, как SA Living.
