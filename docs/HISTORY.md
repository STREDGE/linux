# SA Coop — история версий и найденных проблем

Зачем этот файл: многие странности в коде — следствие конкретных багов на телефоне игрока.
Прежде чем «упрощать», проверь здесь, почему сделано именно так.

## Проблемы и решения

| Симптом у игрока | Причина | Решение |
|---|---|---|
| Эхо-двойник терял задержку на высоком FPS | буфер снимков по кадрам переполнялся | снимки с фиксированной частотой 20/с (`kEchoSampleUs`) |
| Вылет в `CPhysical::RemoveAndAdd` после выхода из дома CJ | `CPopulation::RemoveAllRandomPeds` удалял второго CJ (`CanBeDeleted` не смотрит тип) | `CPed::SetCharCreatedBy(2)` + проверка указателя через пул |
| Двойник «шёл», когда игрок бежал | `moveState` 6 бывает и при ходьбе | спринт передаётся флагом из перехвата `GetSprint` пульта 0 |
| Скольжение после прыжка, кривые круги | прыжки/курс не синхронизировались | счётчик прыжков → `JumpJustDown` пульта 2; курс через камеру |
| Мусор вместо текста в меню | прямая запись в растр RW | загрузка через `RwImage` + `RwRasterSetFromImage`, альфа-тест |
| Пропали 3 кнопки мода Helibrain | перехват `AND_TouchEvent` | убран; касания опрашиваются из массива `Points` |
| Кнопки мода не работали с Touch x4 | Touch x4 подменяет массив `Points` на свой (4 пальца) | чтение через GOT-ячейку `0x851D38` |
| Обрезанный текст, «?» вместо символов | обрезка посреди UTF-8; в Rubik нет «→ ✓ −» | большие буферы, UTF-8-безопасное копирование ника, замена символов |
| Дубль иконки кулака | игра рисует оружие игрока 2 | второй CJ убран из слота на время `Render2dStuff` |
| Камера крутилась при правке раскладки | пальцы шли в игру | `CCamera::Process` пропускается, пока открыт редактор |
| Логи терялись после вылета | файл перезаписывался при запуске | `sacoop_prev.txt` |
| Вылет `CRenderer::PreRender` (0.5.0) | перехват `GenericSave` удалял CJ не из игрового потока | перехват сохранения убран (0.5.6 «прятать» → гонка с дублем CJ), сейв и так пишет только игрока 1 |
| Не показывалось окно разрешения | `dlsym(RTLD_DEFAULT)` не находил AML | `dlopen("libAML.so", RTLD_NOLOAD)`; запасной путь — страница настроек приложения |
| Невидимый двойник после «Новой игры» | CJ создавался, пока модель игрока не готова / в катсцене | задержка 3 с после появления своего CJ, не создавать в катсценах |
| В коопе меню ставило игру на паузу | обычное поведение игры | снимаем `CTimer::m_UserPause` в host/client |
| После выключения коопа пауза возвращалась только после выхода из меню | паузу никто не ставил обратно | флаг `weUnpaused` — ставим паузу сразу |
| Редактор раскладки через «Экран» уводил на карту, неудобно | отдельный экран редактора | элементы встроены в «Настройка сенсоров» игры (`CAdjustableHUD`) |
| Наши элементы прыгали на место при перетаскивании кнопок игры | `self+0x64 == 4` принят за «По умолчанию» | значение 4 игнорируется |
| (тест на ПК) голос рвался каждые 20 мс | `now - t` у беззнаковых уходило «в минус», когда кадр пришёл позже `now` | `Since(now, t)`; время для воспроизведения берётся после приёма |

| (найдено при 0.8.0) пакеты SA Living длиннее 500 байт обрезались | буфер приёма 512 байт | буфер 2048 |
| (0.8.0, тест) машина двойника дёргалась на остановках | позиция переставлялась каждый кадр поверх физики, тормоз выключенного пульта 2 боролся со скоростью | 0.8.1: едет — только поправка скорости; стоит — скорость 0; газ/тормоз/руль друга отдаются на пульт 2 |
| (0.8.0, тест) в одиночку не сесть к двойнику — он выходит вслед за тобой | двойник повторяет всё | 0.8.1: двойник остаётся за рулём, пока ты не сядешь за руль сам / не отойдёшь |
| (0.8.1, тест) у машины двойника пропадала кнопка «сесть» | флаг второго CJ `bDontDragMeOutCar` — `CCarEnterExit::GetNearestCarDoor` тогда не даёт дверь водителя | флаг не ставим; выкидывания нет и так (перехват → пассажиром) |
| (0.8.1, тест) двойник садился, выходил и садился снова | между «садится» и «сел» бывает кадр «пешком» → второму CJ отменялась посадка | выход/отмена — только если «пешком» дольше 0,4 с |
| (0.8.0, тест) обе машины разом улетели за 200 м | копия создалась внутри машины (эхо: 3,5 м на восток) — игра раскидала их столкновением | 0.8.2: пустые случайные машины на месте копии удаляются; в эхо машина двойника сбоку (6 м по правому вектору) |
| (0.8.2, тест) копы арестовали двойника за рулём, он завис в наручниках, копы «залагали», в машину не сесть | арест обрабатывает `CGameLogic::Update` → `CPlayerInfo::ArrestPlayer`, а для второго CJ мы прячем слот — он навсегда в состоянии 63 | перехват `CPed::CanBeArrested` (второй CJ — нельзя), состояние 63 — пересоздать |
| (0.8.3, тест) кнопка «сесть» пропала у всех машин | `CWorld::Process` зовёт `CPlayerInfo::Process` и для игрока 2; кнопка `CWidgetButtonEnterCar` общая — «за второго CJ» игра её прятала (и могла засчитать ему нажатие) | перехват `CPlayerInfo::Process`: для слота второго CJ — пропуск |
| (0.8.3, тест) копия машины: колёса в земле / висит, дрифт на месте | копии ставились высота и наклон твоей машины (в эхо она сбоку, на склоне — другая земля); наклон постоянно перезаписывался | высоту и наклон решает физика, мод правит только x/y и курс; перенос целиком — если разошлись больше 6 м или 3 м по высоте |
| (0.8.4, тест) посадка пассажиром к двойнику срывалась мгновенно (задача 700 сразу кончалась) | стоящая копия на склоне: мод каждый кадр подтягивал её на 0,2 м, физика скатывала обратно — машина «ехала», игра отменяла посадку | расхождение до 0,3 м не правится, ручник, скорость по земле 0 |
| (0.8.4, тест) кнопка «сесть» игры всё равно пропадала у других машин | причина не найдена (в лог добавлено `[КНОПКА]`: флаги ближайшей машины) | своя кнопка «СЕСТЬ» в слое мода |
| (0.8.5, тест) сел пассажиром к двойнику — двойник пропал и снова садился в машину | водителю, к которому садится пассажир, игра ставит состояние 63 (как «арестован»), мод принял это за арест и пересоздал второго CJ | 0.8.6: только пешком, не в машине и дольше 3 с |
| (0.8.6, тест) копия машины ехала с дымом и звуком ручника, при поворотах «переставлялась» вбок | мод каждый кадр задавал скорость и доворачивал курс — колёса не успевали, игра считала занос; руль передавался углом колёс, а пульт ждёт −1..1 | правка только по новому пакету (как в больших мультиплеерах), руль — `fSteer`, ручник — флагом |

## Проверено игроком на телефоне

* Эхо-режим: появление, движение, прыжки, интерьеры, сохранение/загрузка, «Новая игра».
* Меню CO-OP, 4 пальца, раскладка в «Настройка сенсоров», разрешение микрофона, пауза.

## Ещё НЕ проверено

* Всё из 0.8.0 (машины, оружие, урон, смерть, розыск) — написано по отладочной информации игры, в игре не запускалось.

* Игра с другом по сети (Турция ↔ Бельгия через Tailscale).
* Голосовой чат на телефоне (0.6.x) — проверен только на компьютере с поддельным AAudio.
