# SA Coop — как всё устроено

Документ для того, кто продолжает работу (человек или новая сессия Claude). Описывает версию **0.8.0**.
Смещения и символы игры — в [`libgtasa-2.10-arm64.md`](libgtasa-2.10-arm64.md), история багов — в [`HISTORY.md`](HISTORY.md).

---

## 1. Общая схема

```
             телефон A (хост)                               телефон B (клиент)
 ┌──────────────────────────────────────┐        ┌──────────────────────────────────────┐
 │ libGTASA.so (игра)                   │        │ libGTASA.so                          │
 │   CGame::Process ──► coop::OnFrame   │  UDP   │   CGame::Process ──► coop::OnFrame   │
 │        │  CaptureLocal (свой CJ)     │◄──────►│        │                             │
 │        │  Session::Poll/Send         │ :7777  │        │                             │
 │        │  UpdateRemote (второй CJ =  │Tailscale        │                             │
 │        │     CWorld::Players[1])     │        │        │                             │
 │        └─ PumpVoice ◄─► voice (AAudio+Opus)   │        └─ PumpVoice                  │
 │   Render2dStuff ──► overlay::Frame   │        │   (интерфейс так же)                 │
 │   MobileMenu::Render ──► меню CO-OP  │        │                                      │
 └──────────────────────────────────────┘        └──────────────────────────────────────┘
```

* Каждый телефон управляет **только своим CJ**. Друг на твоём телефоне — это второй игрок игры
  (`CWorld::Players[1]`, остаток режима на двоих из PS2), которым управляет «виртуальный джойстик»
  по данным из сети.
* Хост и клиент сейчас симметричны (оба шлют своё состояние 20 раз/с). Разница только в рукопожатии:
  клиент стучится, хост принимает или отклоняет. Позже хост станет главным для миссий/NPC.
* Весь код мода работает в **игровом потоке** (из перехватов). Отдельные потоки — только колбэки AAudio
  (они лишь копируют звук в кольцевые буферы) и вызов `SetConfig` из меню (защищён мьютексом).

## 2. Загрузка мода (`src/main.cpp`)

AML вызывает:

1. `ON_MOD_LOAD`
   * `KeepPreviousLog()` — `sacoop.txt` → `sacoop_prev.txt` (чтобы запись о прошлом вылете не стёрлась).
   * Находит `libGTASA.so`, проверяет ключевые символы (пишет `[OK]/[НЕТ]` в logcat).
   * Создаёт `/storage/emulated/0/SA` и `SA/cleo` (CLEO игрока читает скрипты оттуда; запасной вариант —
     основное создание должно быть в APK, см. `docs/handoff/apk-microphone.md`).
   * Пишет в лог, есть ли разрешение на микрофон.
   * `settings::Load()` → `coop::Install()` (перехваты + `voice::Init`) → `coop::SetConfig()` → `overlay::Init()`.
2. `ON_ALL_MODS_LOAD` — SAUtils грузится после нас (по алфавиту), поэтому кнопки добавляются здесь:
   `overlay::AttachSAUtils` → кнопка **CO-OP** в главном меню и в паузе (`AddSettingsTabButton`,
   `STB_MainMenu` / `STB_Pause`). Если своё меню не запустилось — `menu::Init` (простая вкладка SAUtils).
3. `ON_GAME_CRASH` — пишет сигнал, адрес внутри библиотеки, `pc/lr` и `coop::Where()`
   (строка «что мод делал последним»; обновляется в `OnFrameImpl`).

Логи: `FLogger g_fileLog("sacoop.txt")` → `Documents/AMLModLogs/net.sacoop.mod/sacoop.txt`;
`logger` (AML) → logcat с тегом `SACoop`.

## 3. Настройки (`src/settings.*`)

Конфиг AML: `Android/data/com.rockstargames.gtasa/configs/net.sacoop.mod.ini`.

| Секция / ключ | Значение |
|---|---|
| `[General] Enabled` | 0 — мод ничего не ставит |
| `[General] FriendlyFire` | огонь по своим (тумблер есть, логики ещё нет) |
| `[Network] Role` | `off` / `echo` / `host` / `client` |
| `[Network] HostAddress`, `Port` | адрес хоста (Tailscale), порт (7777) |
| `[Network] Nick` | ник; по умолчанию `Build.MODEL` телефона |
| `[Layout] MicX, MicY, MicScale` (и `Team…`, `Feed…`, `Talk…`) | положение — доля экрана ×10000, масштаб ×100 (0,5–2,5) |

Раскладка по умолчанию (`DefaultLayout`): микрофон `{0.66, 0.13}`, команда `{0.012, 0.30}`,
уведомления `{0.5, 0.66}`, «говорит» `{0.5, 0.03}`, масштаб 1.

## 4. Второй CJ (`src/coop/coop.cpp`)

### Кадр (`OnFrameImpl`, из перехвата `CGame::Process`)

1. `ApplyPendingConfig()` — если меню поменяло режим: убрать второго CJ, остановить сеть и голос,
   запустить новый режим.
2. `CaptureLocal()` — снимок своего CJ в `PlayerStatePacket`: позиция, скорость (м/с), курс, здоровье, броня,
   `moveState`, `moveRatio` (сила движения из `CPlayerPedData+0x20`), счётчик прыжков, флаги
   (в машине, спринт — берётся из перехвата `GetSprint` пульта 0, «говорит»).
3. Режим **echo**: снимки пишутся 20 раз/с в кольцо на 64 элемента; «друг» = снимок 0,5 с назад,
   сдвинутый на 1,5 м на восток. Голос — петля через 0,5 с.
4. Режим **host/client**: `Session::Poll()` → раз в 50 мс `SendPlayerState` → `PumpVoice()` →
   `UpdateRemote(session.Remote())`.

### Появление / удаление

* `SpawnRemote`: `CPlayerPed::SetupPlayerPed(1)` создаёт CJ в слоте 1, затем
  **`CPed::SetCharCreatedBy(2)`** (как скриптовая `CREATE_PLAYER`) — иначе игра удалит его как прохожего.
  Голубая метка на радаре (`SetEntityBlip`).
* Не создаётся первые **3 с** после того, как свой CJ появился на карте (`kSpawnDelayUs`, отсчёт
  `g_localSinceUs`), и во время катсцен (`CCutsceneMgr::ms_running`) — иначе после «Новой игры»
  появлялся невидимый двойник.
* `CheckRemoteAlive`: проверяет, что указатель ещё валиден через пул персонажей (`GetPedRef`/`GetPedFromRef`).
  Если игра сама удалила/подменила персонажа — состояние сбрасывается («самолечение» слота).
* `DespawnRemote`: убрать метку, `RemovePlayerPed(1)`. Вызывается: нет данных 3 с, смена режима,
  загрузка сохранения (`GenericLoad`), перезапуск (`ShutDownForRestart`), катсцена.
* **Сохранение игры НЕ перехватывается** (было в 0.5.0 → вылет). Сейв пишет только ped type 0.

### Движение («виртуальный джойстик»)

Анимации делает сама игра: мы не двигаем модель, а «жмём» пульт 2 за друга.

* У пульта 1 выставлен `DisablePlayerControls` (`CPad+0x110`), иначе он повторял бы касания экрана.
* Перехвачены геттеры `CPad::GetPedWalkLeftRight / GetPedWalkUpDown / GetSprint / JumpJustDown`:
  для пульта 1 возвращаются значения, вычисленные из пакета друга:
  * направление: курс на цель, переведённый в оси джойстика относительно камеры
    (`heading = atan2(-x, -y) − TheCamera.Orientation`, см. справку),
  * сила = `moveRatio × 60` (константа игры), меньше 0,05 — стоит;
  * спринт — флаг `PSF_SPRINT`; прыжок — изменился `jumpCount`.
* Позиция: плавно подтягивается (`kSmoothRate = 12/с`), дальше 10 м — телепорт.
  Дальше 180 м от тебя CJ прячется, остаётся только метка.
* Голова/курс поправляются, если расхождение большое (лог «Проверка джойстика» раз в 15 с).

### Остатки режима на двоих (PS2)

Игра при живом `Players[1]` включает поводок, общую камеру, общую смерть и т.д. Поэтому:

* `IsCoopGameGoingOn`, `IsPlayerUse2PlayerControls` → всегда `false`;
* `CPlayerInfo::Process` для слота второго CJ не выполняется (0.8.4): иначе игра «за него» трогала общую
  кнопку «сесть» и реагировала на твои нажатия;
* на время `CGameLogic::Update`, `CCamera::CamControl`, `CPickups::Update`, `CDarkel::Update`
  второй CJ убирается из слота (`HideRemoteSlot`) и возвращается после;
* то же на время `Render2dStuff` (иначе — вторая иконка оружия, «дубль кулака»).

### Пауза в меню

`KeepWorldRunningInMenu()` (вызывается из `MobileMenu::Render`): в режиме host/client снимает
`CTimer::m_UserPause` — мир и сеть идут, пока открыто меню. Если кооп выключили прямо в меню —
ставит паузу обратно сразу (флаг `weUnpaused`).

## 4а. Общий мир: машины, оружие, урон (`src/coop/sync.*`, с 0.8.0)

Вызывается из `coop::OnFrameImpl`: `sync::Capture` дополняет свой снимок, `sync::Frame` — после
`UpdateRemote`. Игровые пакеты приходят в `sync::OnPacket` (через `Session::SetGameSink`).
Если каких-то функций игры нет — `sync::Install` пишет в лог, и кооп работает пешком, как раньше.

**Машины.** У общей машины сетевой номер `id` (старший бит — чья: хост 0, клиент 0x8000).
* Своя становится общей, когда твой CJ в неё садится или сидит (`ReadLocalSeat`: задачи 700/701 →
  `CTaskComplexEnterCar::m_pTargetVehicle`). На время «общести» помечается `VehicleCreatedBy = 2`
  (игра не удалит), потом возвращается как было. Дальше 220 м от обоих и никем не занята — `VEHICLE_GONE`.
* Состояние (`PKT_VEHICLE`: позиция, правый/передний векторы, скорости, здоровье, руль/газ/тормоз, цвета,
  сирена, гудок, колёса, «взорвана») шлёт **тот, чей игрок за рулём**; никто — хозяин машины.
  20 раз/с, если машина занята или едет, иначе раз в секунду.
* У друга — копия: `CCarCtrl::CreateCarForScript` (модель грузится `CStreaming::RequestModel`, через 1,5 с —
  `LoadAllRequestedModels`). Копия подтягивается к присланному (больше 6 м — перенос), ставится
  скорость, руль/газ, флаги. Удаление — `CWorld::Remove` + деструктор из vtable (+0x08), как `CCarCtrl`;
  перед этим игроки высаживаются. Дальше 360 м — копия убирается (создастся снова ближе 300 м),
  6 с без вестей — тоже. Если в уходящей копии сидит твой CJ — машина становится твоей (`AdoptCopy`).
* Копия правится **только когда пришёл новый пакет** (`appliedSeq`), между пакетами её ведёт физика игры:
  второму CJ на пульт 2 отдаются газ/тормоз/руль/ручник водителя (руль — `fSteer` `+0x730`, −1..1; пульт = −руль·128).
  На пакет: дальше 6 м или 3 м по высоте — перенос целиком; стоит (меньше 0,3 м/с, ближе 0,8 м, курс < 10°) —
  не трогаем; разошлись больше 1,2 м или 12° — ставим положение и поворот; скорость и вращение — как у друга
  + поправка к точке до 3 м/с. Каждый кадр — только вид (здоровье, цвета, сирена, гудок, колёса). Газ/тормоз/руль водителя отдаются
  второму CJ через перехват `CPad::GetAccelerate/GetBrake/GetSteeringLeftRight/GetHandBrake` пульта 2.
* Перед созданием копии пустые случайные машины ближе 5,5 м удаляются (`ClearSpaceFor`, пул машин — записи 0xC68).
* Эхо-режим: свои пакеты возвращаются через 0,5 с с номером `^ 0x8000`; двойник сдвинут на 3,5 м на восток,
  его машина — на 6 м вдоль правого вектора твоей. Вышел из-за руля —
  двойник остаётся за рулём (`EchoUpdate`, «hold»), чтобы можно было сесть к нему пассажиром.

**Посадка второго CJ** (`ManageRemoteSeat`): друг в машине → задача игры «сесть водителем/пассажиром»
(анимация), не сел за 4 с или дальше 12 м — `CCarEnterExit::SetPedInCarDirect`. Друг вышел → задача
«выйти», за 2,5 с не вышел — `CTaskSimpleCarSetPedOut` с `m_bWarpingOutOfCar`. Пока второй CJ в машине
или садится, `coop` его не двигает (`sync::RemoteBusy`). Выход/отмена посадки — только если друг «пешком»
дольше 0,4 с. Флаг «не вытаскивать из машины» НЕ ставить: с ним игра прячет кнопку «сесть».

**Пассажиром к другу.** Перехват конструктора `CTaskComplexEnterCarAsDriver` (C1 = C2): если за рулём
второй CJ, вместо него строится `CTaskComplexEnterCarAsPassenger` на свободное место. Камера пассажира,
стрельба из окна — штатные игры.

Своей кнопки «сесть» нет (была в 0.8.5, игрок против): только кнопка игры. Каждый её показ/скрытие пишется
в лог `[КНОПКА ИГРЫ]` (перехват `CWidgetButtonEnterCar::SetEnterCarVehicleType`, с адресом вызвавшего кода).
Обычная игра тоже прячет кнопку, если CJ не смотрит на машину (`CPlayerInfo::EvaluateCarPosition` — угол).

**Оружие.** В снимке: оружие в руках, «целится», точка прицела (захват цели / последний выстрел / вперёд),
счётчик ударов (перехват `CPad::MeleeAttackJustDown` пульта 0; второму CJ «нажимается» пульт 2).
Второму CJ выдаётся то же оружие (`GiveWeapon` 9999 патронов), при прицеле — `SetAimFlag` +
`CPedIK::PointGunAtPosition`.

**Выстрелы.** Перехват `CWeapon::Fire` своего CJ; линия пули — из `CWeapon::DoBulletImpact` внутри
него (стрельба не через `Fire`, например из машины, — шлётся прямо из `DoBulletImpact`). `PKT_SHOT`:
оружие, где стоял стрелок, начало и конец. У друга `CWeapon::Fire` второго CJ из той же точки
(со сдвигом на его позицию) в ту же цель; «попал во второго игрока» — пуля летит в тебя.

**Урон** — перехват `CPedDamageResponseCalculator::ComputeDamageResponse`:
* второй CJ у себя урона не получает никогда; если бил твой CJ (или машина, где он за рулём) и огонь по
  своим разрешён — `REL_DAMAGE` (оружие, часть тела, сила) надёжным событием;
* по тебе урон от второго CJ / его машины гасится; приходит событием → `CWeapon::GenerateDamageEvent`
  (реакция, кровь, смерть — как от обычного удара);
* «огонь по своим» решает хост (`PSF_FF` в его снимке), клиент берёт его значение.

**Смерть.** Свой CJ мёртв → `PSF_DEAD`. У друга второй CJ получает смертельный урон (разрешённый) и лежит;
друг снова жив (больница) — второй CJ убирается и создаётся заново.

**Выдача оружия** (0.8.10, только хост): меню CO-OP → «Хост» → «Оружие» (`DrawWeapons` в `overlay.cpp`) →
`coop::GiveWeapon` (очередь под мьютексом) → в игровом кадре себе `sync::GiveWeaponLocal` (модель грузится,
`CPed::GiveWeapon`, в руки), другу — надёжное событие `REL_GIVE_WEAPON`; клиент принимает только как клиент,
пишет в ленту «Хост выдал тебе …» (`coop::PopNotice`).

**Розыск.** Режим выбирает хост (тумблер «Общий розыск», конфиг `[General] SharedWanted`, флаг `PSF_SHARED_WANTED`
в снимке хоста; клиент берёт значение хоста). Выключен — у каждого свой розыск, синхронизации нет. Звёзды в снимке. Друг поднял выше твоих — `CWanted::SetWantedLevel`; друг сбросил, а у тебя
столько же, сколько было у него, — `CheatWantedLevel` (сбросили вместе).

**Отношения педов** (0.9.1, `MirrorPlayer2Relations`): в `CPedType::ms_apPedTypes` (32 типа × 5 масок:
уважение, симпатия, безразличие, неприязнь, ненависть; бит = 1 << тип) бит PLAYER2 ставится как бит PLAYER1 —
банды и прохожие относятся ко второму CJ как к тебе. Раз в секунду: скрипты меняют отношения по сюжету.
Копы целятся по розыску своего игрока (`FindPlayerPed`) — чтобы копы хоста гонялись и за другом, это делается
вместе с общими педами (план, п. 4).

**Интерьеры.** `PlayerStatePacket::area` = `CGame::currArea`; второму CJ ставится `m_areaCode` —
игра сама показывает его только в том же интерьере.

**Подробный лог** (0.8.7, `TraceTransitions`/`DebugTick` в `sync.cpp`): сразу — у тебя и второго CJ задача,
состояние, машина/место/кто за рулём, оружие, прицел, присед, жив/погиб, интерьер, здоровье/броня, управление
выключено игрой; `[РОЗЫСК]`; `[СЕТЬ]` пропуски пакетов друга > 300 мс и потери; `[ПЕДАЛИ ВТОРОГО CJ]`;
`[КНОПКА ИГРЫ]`; `[ПОСАДКА]` (каждый «сесть за руль» игры, кто вызвал, перенаправление в пассажиры);
`[УРОН]` каждый случай по тебе/второму CJ (от кого, сколько, применён ли); `[ВЫСТРЕЛ]` (до 10/с);
`[МАШИНА id] ПЕРЕНОС` с числами. Раз в секунду — снимки обоих CJ, `[ДРУГ]` (где по пакету, насколько второй CJ
от этой точки), `[МАШИНА id]` (где, курс, скорость, вращение, руль/газ/тормоз/ручник, режим, расхождение м/°,
поправки, переносы, пакеты).

## 4б. Вход сразу в мир хоста (`src/coop/world.*`, 0.9.0)

* **Сеть в меню.** Пока игра не загружена, `CGame::Process` не идёт — `coop::MenuTick` (из перехвата
  `MobileMenu::Render`) применяет режим и крутит `Session::Poll` + `world::Tick`.
* **Друг (клиент)** после «Принять» раз в секунду шлёт `PKT_WORLD_REQ` (номер передачи), пока не пойдут куски.
* **Хост** в игровом кадре сохраняет мир: перехват `CGenericGameStorage::MakeValidSaveName` подменяет имя
  на `SACoopWorld.b`, затем `C_PcSave::SaveSlot(PcSaveHelper, 0, false)` — как обычное сохранение, ячейки
  хоста не трогаются. Файл читается `OS_FileOpen(1, …)` и уходит `PKT_WORLD_CHUNK` по 1024 байта (окно 32,
  повтор через 250 мс), друг подтверждает каждый `PKT_WORLD_ACK`.
* **Друг** пишет файл `SACoopHost.b` (`OS_FileOpen(1, …, 1)` + проверка чтением), затем загрузка:
  из главного меню — в `MobileMenu::Update` (`coop::MenuUpdateTick`), как кнопка «Продолжить»:
  подмена имени на `SACoopHost.b`, `lastSaveForResume = 9`, `CheckSlotDataValid`, `MainMenuScreen::OnResume`;
  из игры — в игровом кадре `Menu_LoadSlot(9)` + `OnResume`. После `GenericLoad` — `world::AfterGameLoaded`:
  подмена загрузки снята, `lastSaveForResume` вернули, включена защита (сохранения в ячейку «продолжить» друга
  и 10-ю идут в `SACoopHost.b`, пока он клиент), и `CPed::Teleport` рядом с хостом (тот же интерьер).
* **Экран** `DrawJoin` (overlay): «Подключение к хосту» (ждём «Принять») 5 % → «Хост сохраняет мир» 15 % →
  «Получаю мир хоста» 15–80 % → «Загружаю мир хоста» 85 % → «Переношу к хосту» 95 %; «Отмена» выключает кооп.
  Хосту — уведомления «Друг загружается в твой мир…», «Мир отправлен другу».

## 5. Сеть (`src/net/`)

UDP, неблокирующий сокет, порт 7777, всё в игровом потоке. Протокол — `protocol.h`, **версия 9**
(при несовместимом изменении — увеличить `kProtocolVersion`; пакеты другой версии игнорируются с
одной строкой в логе).

| Пакет | Направление | Когда |
|---|---|---|
| `HELLO(nick)` | клиент → хост | раз в секунду, пока не ответят |
| `ACCEPT(nick)` | хост → клиент | игрок нажал «Принять» (или тот же друг вернулся в течение 5 мин) |
| `DENY(reason)` | хост → клиент | отклонён / занято / запрос истёк (15 с); также «ухожу» при `Stop()` |
| `PING/PONG` | оба | раз в секунду после принятия, пинг = RTT |
| `PLAYER_STATE` | оба | 20 раз/с, номер пакета отбрасывает старые |
| `VOICE` | оба | кадр Opus 20 мс: `seq`, `spurt` (номер нажатия), `len`, данные (≤255 байт) |
| `MOD` | оба | данные другого мода (SA Living), канал + до 1100 байт |
| `VEHICLE` / `VEHICLE_GONE` | оба | состояние общей машины / машина больше не общая (0.8) |
| `SHOT` | оба | выстрел для повтора у друга (0.8) |
| `WORLD_REQ` / `WORLD_CHUNK` / `WORLD_ACK` | друг ↔ хост | передача мира хоста (0.9.0) |
| `RELIABLE` / `ACK` | оба | событие с подтверждением (урон): повтор раз в 150 мс до ACK, не дольше 15 с; повторы отбрасываются по номеру |

Состояния связи (`Link`): `Idle` (хост ждёт) → `Pending` (пришёл запрос, на экране «Принять/Отклонить»)
→ `Connected`; у клиента `Requesting` → `Connected` / `Denied`. 10 с без пакетов — связь потеряна
(`DropPeer`). Отклонённый адрес игнорируется 30 с. События для интерфейса — `PopEvent`
(запрос, подключился, отключился, отказ, занято, истёк).

Адрес Tailscale ищется по интерфейсам (`SIOCGIFCONF`, диапазон `100.64.0.0/10`).

## 6. Голос (`src/voice/`)

```
микрофон ─AAudio колбэк─► g_inRing ─Pump: пересчёт частоты→48к─► Opus encode (20 мс, 24 кбит/с, FEC)
     ─► g_txQueue ─PumpVoice─► Session::SendVoice ─UDP─►
     ─► Session (PKT_VOICE) ─► voice::PushReceivedFrame ─► слоты (32) ─Pump: decode / FEC / PLC─►
     ─► пересчёт 48к→частота динамика ─► g_outRing ─AAudio колбэк─► динамик
```

* **AAudio грузится через `dlopen("libaaudio.so")`** — на Android < 8 мод работает без голоса.
* Микрофон: `PERFORMANCE_MODE_NONE`, `InputPreset = VOICE_COMMUNICATION` (телефон сам давит эхо и шум).
  Открывается при первом нажатии, `requestStart` на нажатие, `requestStop` через 250 мс после отпускания
  (хвост слова). Каждое нажатие — новый `spurt`.
* Динамик: `LOW_LATENCY`, открывается при первом голосе, останавливается после 10 с тишины.
* Внутренняя частота 48 кГц моно (кадр 960). Если телефон дал другую — линейный пересчёт (`Resampler`).
  Стерео-поток → сводится в моно / дублируется.
* Буфер приёма: ждём 3 кадра (60 мс) или 120 мс до начала фразы; держим в динамике ~100 мс;
  потерянный кадр — FEC из следующего или PLC; больше 12 кадров в очереди — догоняем, выбрасывая старое;
  400 мс без пакетов — фраза закончилась. Статистика — в лог `[ГОЛОС] друг замолчал: кадров …, потеряно …`.
* Отвалился поток (наушники, смена устройства) — колбэк ошибки ставит флаг, `Pump` переоткрывает.
* Все разности времени — через `Since(now, t)` (без ухода в минус у беззнаковых; это был баг).
* Режим echo: `SetLoopback(true, 500)` — свои кадры возвращаются в декодер через 0,5 с;
  «Двойник говорит» горит, пока звучит эхо (`voice::Playing()`).
* Opus 1.5.2 собирается статически (`jni/opus.mk`, float, без NEON-оптимизаций).

Тест на компьютере (без телефона): поддельный `libaaudio.so` (поток, вызывающий колбэки; на микрофон —
синус 440 Гц на 44,1 кГц, динамик 48 кГц стерео пишет в буфер) + анализ Гёрцеля и поиск провалов.
Последний прогон: эхо — 22/23 окна чистый тон, сеть с 5% потерь и перестановкой — 21/23, провалов 0.
(Сам тест в репозиторий не положен — при необходимости воссоздать по описанию.)

## 7. Интерфейс (`src/ui/overlay.cpp`, `imgui_rw.cpp`)

### Отрисовка

Dear ImGui 1.90.9, бэкенд — `imgui_rw.cpp`: вершины ImGui → `RwIm2DRenderIndexedPrimitive`
(вершина 28 байт: x, y, z, rhw, color, u, v), текстура шрифтов через
`RwImageCreate / AllocatePixels / RwImageFindRasterFormat / RwRasterCreate / RwRasterSetFromImage`
(прямая запись в растр давала мусор), альфа-тест выключается на время отрисовки (render state 29/30).
Шрифты вшиты (`fonts_data.h`): Russo One (заголовки), Rubik Medium (текст), JetBrains Mono Bold (цифры),
только латиница + кириллица. **В Rubik нет «→» и «✓»** — использовать «>» и рисовать галочку линиями.

Масштаб: всё в единицах `U(x)` от высоты экрана; `g_s` — масштаб текущего элемента раскладки.

### Касания

Не перехватываем `AND_TouchEvent` (ломало кнопки других модов). Опрашиваем массив игры `Points`
через **GOT-ячейку `0x851D38`**: мод Touch x4 подменяет её на свой массив на 4 пальца — тогда читаем 4.
`Finger g_f[4]`: `Held/HeldFrom/Clicked/PressedIn` — каждая кнопка реагирует на палец, начавший касание
на ней (можно держать джойстик и жать микрофон). Опрос не чаще раза в 4 мс (два наших кадра в одном
кадре игры не «съедают» нажатия друг у друга).

### Перехваты

| Функция | Зачем |
|---|---|
| `MobileMenu::Render` | после меню игры: `KeepWorldRunningInMenu` + `Frame(true)` (наше меню CO-OP, запросы, уведомления) |
| `MobileMenu::Update` | не обновлять меню игры, пока открыто наше меню / редактор / запрос (+0,3 с и пока палец не отпущен) |
| `Render2dStuff` | слой поверх игры `Frame(false)`; на время оригинала второй CJ убран из слота |
| `CAdjustableHUD::Draw` | экран «Настройка сенсоров»: наши элементы рисуются и двигаются среди кнопок игры |
| `CAdjustableHUD::Update` | ловим «Сохранить»/«Отмена» игры: `self+0x64` было 2/3 и стало −1, `self+0x52E == 1` (закрытие) |
| `CCamera::Process` | пропускается, пока открыт наш редактор (иначе пальцы крутили камеру) |

**Значение 4 в `self+0x64` не использовать** — приходит не только от «По умолчанию», но и при перетаскивании
кнопок игры (из-за этого наши элементы сбрасывались на каждом движении).

### Что рисуется

* **Меню CO-OP** (`DrawMenu`): 4 карточки режимов (выкл / тест / хост / подключиться), статус-плашка
  (состояние связи, пинг), свой адрес Tailscale + «копировать», ввод адреса хоста (своя цифровая клавиатура
  + «вставить» с вытаскиванием IPv4 из любого текста), ник (+ «вставить»), тумблер «огонь по своим»,
  большая кнопка «Применить». Режим применяется через `coop::SetConfig` и сохраняется в конфиг.
* **Слой в игре** (`DrawHudItems`): панель «Команда» (ты и друг: ник, здоровье, броня, пинг, расстояние,
  значок «говорит», серая строка при потере связи), плашка «<ник> говорит» (полоски — реальная громкость),
  кнопка микрофона (зажал — `coop::SetTalking(true)`, полоски — громкость микрофона), лента уведомлений.
* **Запрос на подключение** (`DrawRequest`): ник, таймер 15 с, «Принять / Отклонить».
* **Разрешение на микрофон** (при первом нажатии кнопки, если нет): `Activity.requestPermissions`
  (Activity берётся через `AML::GetCurrentActivity`: `dlopen("libAML.so", RTLD_NOLOAD)` + `dlsym`);
  если окно показать нельзя / уже отказывали — открывается страница приложения в настройках Android.

### Раскладка

Элементы (`L_MIC, L_TEAM, L_FEED, L_TALK`) редактируются **в экране игры «Настройка сенсоров»**
(`DrawEditor(team, false)` внутри `CAdjustableHUD::Draw`): тянуть пальцем, щипок — масштаб.
Сохранение/отмена — кнопками самой игры. `g_layout` — сохранённая, `g_editLayout` — правка.

### Превью на компьютере

`tools/preview/build.sh` (запускать из любой пустой папки, например scratchpad) собирает `overlay.cpp`
с `-DSACOOP_PREVIEW`, заглушками игры/AML/SAUtils/voice и программным растеризатором и сохраняет
картинки `.ppm`: меню в разных режимах, запрос, команда, редактор, экран настройки сенсоров.
При добавлении в `overlay.cpp` вызовов новых модулей — добавить заглушки в `tools/preview/preview.cpp`.

## 8. Android (`src/platform/android.cpp`)

JNI: `JNIEnv` текущего потока (подключается к Java при необходимости), контекст — `aml->GetAppContextObject()`: буфер обмена (`ClipboardManager`),
`Build.MODEL`, `checkSelfPermission`, `requestPermissions`, `ACTION_APPLICATION_DETAILS_SETTINGS`.
`ExtractIPv4` — первый `a.b.c.d` из произвольного текста.

## 9. Сборка и выпуск

* `ndk-build` (NDK r27c, `arm64-v8a`, `android-21`, `c++_static`). `jni/Android.mk` подключает `jni/opus.mk`.
* Версия — в `MYMODCFG(...)` в `src/main.cpp` **и** в `release/README.txt`.
* Выпуск: собрать → `cp libs/arm64-v8a/libSACoop.so release/` → дописать строку в `release/README.txt` →
  коммит → push в рабочую ветку. `.gitignore` пропускает только `release/*.so`.
* Протокол менять → увеличить `kProtocolVersion` и предупредить игрока, что обновиться должны оба.
