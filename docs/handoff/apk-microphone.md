# Задание для сессии на компьютере: разрешение на микрофон в APK

Вставь этот текст первым сообщением в сессию Claude Code, запущенную **на компьютере**
в папке проекта, где лежит APK GTA San Andreas с AML.

---

Нужно добавить в APK GTA San Andreas (Android 2.10, 64-bit, уже пропатчен под AML) разрешение
на микрофон, чтобы мод SA Coop (голосовой чат в кооперативе) мог записывать звук.

Что сделать:

1. Найди в папке проекта APK игры с AML (~300 МБ). Если их несколько — спроси, какой.
2. Проверь, какие инструменты есть: `java`, `apktool`, `zipalign`, `apksigner` (Android build-tools).
   Чего нет — **сначала спроси**, потом ставь.
3. Посмотри текущую подпись: `apksigner verify --print-certs <apk>`. Запиши, чем подписан
   (тестовый ключ MT Manager / APK Editor / свой ключ / другое).
4. Распакуй без исходников (`apktool d -s <apk> -o work`), в `work/AndroidManifest.xml` добавь
   рядом с другими разрешениями:
   `<uses-permission android:name="android.permission.RECORD_AUDIO"/>`
   Больше ничего не меняй (библиотеки `lib/arm64-v8a/*.so`, assets — как есть).
5. Собери (`apktool b work -o unsigned.apk`), выровняй (`zipalign -p -f 4`), подпиши (`apksigner sign`).
   - Если исходная подпись — известный публичный тестовый ключ (например, MT Manager / AOSP testkey),
     подпиши **тем же** ключом: тогда APK встанет поверх старого без удаления игры.
   - Иначе создай новый ключ и **предупреди**: перед установкой игру придётся удалить, а значит
     заранее скопировать `Android/data/com.rockstargames.gtasa` и `Android_unprotected` (сейвы и моды).
6. Проверь результат: `apksigner verify` и что в манифесте есть RECORD_AUDIO
   (`aapt dump permissions` или повторный `apktool d`).
7. Ничего не ставь на телефон сам. Скажи путь к новому APK и встанет ли он поверх старого.

После установки: Настройки Android → Приложения → GTA SA → Разрешения → Микрофон → Разрешить.

Контекст: мод SA Coop — репозиторий github.com/STREDGE/linux, ветка `ccr-ffecc13b-oyswo0`
(в эту сессию его клонировать не обязательно, задача только про APK).
