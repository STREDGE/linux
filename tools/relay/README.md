# Сервер-посредник SA Coop (коды комнат вместо Tailscale)

Маленькая программа `relay.py`: хост открывает комнату (6 цифр), друг вводит код — сервер пересылает пакеты.
Ничего не хранит, аккаунтов нет. Проверено на компьютере (комната, вход по коду, пересылка в обе стороны).

## Запуск на своём сервере (VPS, любой Linux)
```sh
python3 relay.py 7777        # открыть UDP-порт 7777 в файрволе
```

## В моде (у обоих)
`Android/data/com.rockstargames.gtasa/configs/net.sacoop.mod.ini`:
```
[Network]
Relay=адрес_сервера:7777
```
* Хост: CO-OP → «Хост» → «Открыть мир» — вместо адреса Tailscale будет **код комнаты**, «Копировать».
* Друг: CO-OP → «Подключиться» → вводит 6 цифр кода (или, как раньше, адрес Tailscale) → хост жмёт «Принять».
* `Relay` пусто — всё как раньше, напрямую через Tailscale.

Служебные пакеты: `SCRL` + `H`/`C` + код (хост держит комнату раз в 5 с, друг заходит раз в секунду);
ответ `SCRLO…` — ок, `SCRLN…` — комнаты нет. Остальное пересылается как есть.
