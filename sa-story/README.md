# SA Story — свой сюжет (третий мод, `libSAStory.so`)

Отдельный AML-мод: **только сюжет**. Решение игрока: «все миссии снести и сделать свой сюжет», сначала соло,
другой герой, боевик; голоса — позже (игрок озвучит реплики через ИИ и пришлёт файлы).
С коопом и SA Living не смешивать: свой код в `sa-story/src`, общие — только `third_party/`.

## Как устроено

| Файл | Что делает |
|---|---|
| `src/main.cpp` | вход AML, кадр игры (`CGame::Process`), время мода в кадре (строка `[ВРЕМЯ]` раз в 30 с) |
| `src/story.cpp` | режим «свой сюжет»: новая игра, блок родных миссий, файл состояния у сохранения, модель героя |
| `src/engine.cpp` | движок миссий: шаги, маркеры старта, проверки провала, награда, уборка |
| `src/missions.cpp` | **сами миссии** (пока только пробная) |
| `src/ui.cpp` | текст на экране (ImGui + RenderWare): название, цель, реплики, таймер, счётчик, итог |
| `src/script.cpp` | команды сценария игры из C++ (копия исполнителя из SA Living) |
| `src/log.cpp` | лог в общий `Documents/SA_LOG.txt`, строки «С» |

### Выключение родного сюжета (разбор `mainV1.scm`, см. `docs/main-scm-notes.md`)
* «Новая игра» (`Menu_NewGame`) при `[Story] NewGameIsStory = 1` → свой сюжет.
* Миссия **2 INTRO** (вступление) не запускается (`0417` в `ProcessCommands1000To1099`). Плюс: INTRO закрывает
  магазины/парикмахерские/спортзалы (`SWITCH_ENTRY_EXIT … 0`), ставит барьеры между городами (`REQUEST_IPL BARRIERS1/2`)
  и запускает поток контакта INT — ничего этого нет. После пропуска мод ставит `$92 = 1` («вступление пройдено»,
  на нём поток HELP), даёт управление и открывает экран (`DO_FADE 1500 1`).
* `03EE CAN_PLAYER_START_MISSION` в потоках сюжета (INT, SWEET, CRASH, RYDER, SMOKE, STRAP, LA1FIN, CESAR, BCESAR,
  BCRASH, CAT, TRU, GARAGE, SCRASH, WUZI, SYND, STEAL, ZERO, DESERT, CASINO, VCRASH, DOC, HEIST, MANSION, GROVE, RIOT)
  → «нельзя»: маркер родной миссии не срабатывает. Подработки, гонки (35), автошкола (71), лётная школа (83),
  спортзалы, покупки — не трогаем.
* Запасной блок: `0417` с номером 11…112 (кроме 35/71/83) → не запускать, вернуть управление/камеру/экран.
* Значки родных контактов (метка типа 5, кроме 31/32/35/54) прячутся раз в 2 с.
* Город «открывается» статом 181 (`GET_INT_STAT 181` в main, поток OPENUP) — пригодится, когда сюжет пойдёт в СФ/ЛВ.

### Состояние по сохранениям
`<Android/data/…/files>/SAStory/<имя файла сохранения>.txt` (`story`, `progress`, `hero`). Пишется при сохранении игры,
читается при загрузке. Нет файла — обычная игра, мод ничего не делает. Перед сохранением метки маркеров убираются
(иначе после загрузки были бы двойные).

### Как написать миссию
В `src/missions.cpp`:
```cpp
void Mission1(Builder& b)
{
    b.Say("Имя", "Реплика", 4.0f, kGold /*, "voice_id" — голос позже */);
    b.Car("car", 560, Vec{x, y, z}, heading);   b.Protect("car", "Машина уничтожена");
    b.EnterCar("car", "Садись в машину");
    b.TimeLimit(120);  b.GoTo(Vec{x, y, z}, 6.0f, "Езжай туда", "car");  b.TimeLimit(0);
    b.Enemy("e1", 7 /*тип педа*/, 102 /*модель*/, Vec{...}, heading, 22 /*оружие*/, 200);
    b.KillEnemies("Убей всех");  b.Wanted(2);  b.LoseWanted("Уйди от полиции");
}
Register({ 0 /*номер в сюжете*/, "M1", "НАЗВАНИЕ", Vec{маркер}, 10000 /*награда*/, { модели… }, Mission1 });
```
Маркер миссии `N` виден, когда пройдено ровно `N` миссий сюжета. Пробная (`id = -1`) — всегда, если `[Story] TestMission = 1`.
Модели из списка грузятся до первого шага и выгружаются после миссии. Все команды — `src/engine.cpp` (номера опкодов
в комментариях; описание — Sanny Builder `sa_mobile.json`).

## Настройки (`net.sastory.mod.ini` в папке настроек AML)
```
[General] Enabled=1
[Story]   NewGameIsStory=1   TestMission=1   HeroModel=0   ; 0 — CJ, иначе номер модели педа
```

## Сборка
```sh
cd sa-story && /opt/android-ndk-r27c/ndk-build NDK_PROJECT_PATH=. APP_BUILD_SCRIPT=jni/Android.mk NDK_APPLICATION_MK=jni/Application.mk -j8
cp libs/arm64-v8a/libSAStory.so release/
```

## Что дальше
1. Игрок присылает сюжет → докрутить, согласовать, написать миссии.
2. Список реплик для озвучки (кто, текст, имя файла) → игрок озвучивает → проигрывание файлов в `Say` (поле voice).
3. Герой: модель (`HeroModel`), проверить магазины одежды/парикмахерские с не-CJ (могут падать — тогда закрыть их).
4. Кооп — потом (ведёт хост, как родные миссии в SA Coop).
